# Indonor Shop

## Run in VS Code (recommended)
1. Extract this ZIP.
2. In VS Code choose **File → Open Folder** and open the `indonor-shop` folder (the one containing `package.json` and `index.html`).
3. Open **Terminal → New Terminal**.
4. Run `npm.cmd install` and wait for it to complete.
5. Run `npm.cmd run dev`.
6. Open the local URL printed in the terminal (usually `http://localhost:5173/`). Do not use Live Server for the Vite app.
